# 配達マップ

自建的「住宅地图」：国土地理院地图 + 建筑轮廓 + 自己积累的表札标注。数据只存在手机本地。

## 用法
- **点建筑**：新建标注（自动框住整栋建筑，自动推算到丁目），输入表札即可保存
- **长按空地**：在没有建筑轮廓的地方放一个点
- **点已标注的建筑**：查看 / 修改 / 导航；保存会刷新「确认日期」
- **入口**：编辑时点「点地图设置」，再点一下入口位置（旗竿地、后排房子用）
- **搜索**：表札、住所、部屋、备注都能搜
- **今日**：粘贴当天配送单（一行一件），自动匹配到已标注的房子，并在地图上编号显示
- **航拍**：切换航拍照片，适合确认屋顶位置
- **☰ 菜单**：统计、导出备份（JSON / CSV）、导入备份

标注超过 180 天没更新，会显示为浅色和虚线，提醒复查。

## 数据来源
- 地理院タイル（淡色地図・写真）、国土地理院最適化ベクトルタイル（建物 BldA）
- 国土地理院 逆ジオコーダ / 住所検索 API
